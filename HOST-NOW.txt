TCW HR SOFTWARE - HOST ANYWHERE
================================

This package is NOT tied to Netlify.

EASIEST PRODUCTION METHOD:
1. Install Docker + Docker Compose on a VPS/server.
2. Copy .env.hosting.example to .env.
3. Put your real domain, passwords, SMTP and S3 settings in .env.
4. Run: npm run host:check
5. Run: docker compose --env-file .env -f docker-compose.production.yml --profile proxy up -d --build

Use two DNS names:
HR          hr.yourdomain.com
Super Admin admin.yourdomain.com

For hosting without Docker, read HOST-ANYWHERE.md.
