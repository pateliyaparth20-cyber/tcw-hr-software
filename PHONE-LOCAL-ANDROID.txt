TCW HR Software v1.2.9 - Android Local Phone Test

Why this exists
---------------
If the same Android phone is providing the Wi-Fi hotspot used by the laptop, the phone may block access back to hotspot clients. The application can be healthy on 0.0.0.0 and still be unreachable from that phone.

Local USB method
----------------
1. Install Android Platform Tools (ADB) on Windows.
2. On the Android phone enable Developer options and USB debugging.
3. Connect the phone to the laptop with a USB data cable.
4. Accept the USB debugging authorization prompt on the phone.
5. In this project folder run:

   npm ci
   npm run phone:usb

6. Keep the USB cable connected.
7. On the phone browser open:

   HR:          http://127.0.0.1:3000/login
   Super Admin: http://127.0.0.1:3001/login

This remains fully local. No Cloudflare/LocalTunnel/public URL is used.
Production deployments should use normal HTTPS domains instead.
