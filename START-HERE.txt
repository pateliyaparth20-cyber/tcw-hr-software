TCW HR Software v1.3.0 — START HERE
===================================

LOCAL DEMO (fastest)
1. Install Node.js 22.12+.
2. In this folder run: npm ci
3. Run: npm run demo  (recommended stable PC + phone mode)
4. Open HR: http://localhost:3000/login
5. Open Super Admin: http://localhost:3001/login

LOCAL / LAN PHONE TEST
- Read PHONE-LOCAL-ANDROID.txt
- Run: npm run configure:lan
- Restart the demo and open the printed HR Mobile URL on the same Wi-Fi.
- For USB Android local testing, use: npm run phone:usb

TRIAL FOLLOW-UP
- Super Admin: open /trials or choose “Trial follow-up” in the sidebar.
- New free-trial signups appear automatically with contact details, usage, expiry and follow-up status.
- Expired unresolved trials are marked “Call due”.
- See docs/V1.2.9-TRIAL-FOLLOWUP.md for details.

PRODUCTION
- Do not expose demo/PGlite mode publicly.
- Read START-V1.1-PRODUCTION.txt and docs/V1.1-PRODUCTION-BLUEPRINT.md.
- Use HTTPS, PostgreSQL, Redis, SMTP/S3, production secrets and npm run production:check.

VALIDATION
npm run typecheck
npm test
npm run test:integration
npm run build
npm run test:ssr

NATIVE CLIENTS
- Android wrapper source: native/android
- Windows wrapper source: native/windows
- Signed APK/EXE URLs can be exposed through NEXT_PUBLIC_ANDROID_APK_URL and NEXT_PUBLIC_WINDOWS_INSTALLER_URL.

Release version: 1.3.0
