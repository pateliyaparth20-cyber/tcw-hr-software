# TCW HR Software v0.3.0 — Motion & UI polish

This release adds a professional motion layer without adding a new animation dependency.

## Added
- Soft page-entry transitions on navigation.
- Animated selected-sidebar accent and icon micro-interactions.
- Button shine, press, hover and focus feedback.
- Stat/card/panel hover depth and lightweight motion.
- Table row entrance and hover feedback.
- Animated dashboard attendance line chart.
- Modal backdrop blur + scale/fade entry.
- Toast slide/fade feedback.
- Login ambient background motion, staged copy entry and interactive chips.
- Branded route loading screen.
- Improved input focus rings and hover states.
- Mobile-specific motion reductions.
- Full `prefers-reduced-motion` fallback for accessibility.

## Design intent
Animations are intentionally short and subtle. They reinforce hierarchy and state changes rather than delaying actions or hiding information.
