# TCW HR Software 1.2.9 — audit and stability fixes

This package was reviewed for cross-device reliability, stale release material and obvious runtime hazards without changing the product's core data model or internal compatibility identifiers.

## Fixed
- Stable local-session storage with migration from older 1.2.x browser session keys.
- Session cleanup and redirect handling on failed authentication/logout paths.
- Mobile navigation body-scroll lock, Escape-to-close behavior and accessibility state.
- API proxy timeout/error handling with a clear 503 response when the API is unavailable.
- PWA shell cache bumped to 1.2.9 so older cached shell assets are evicted.
- Android WebView state restoration, file upload chooser support, same-origin navigation checks, external-link handling, and release/debug cleartext policy.
- Windows desktop wrapper same-origin navigation enforcement, safe external-link handling, smaller-window support and current version metadata.
- Responsive CSS/touch sizing for small phones, narrow desktops, dialogs, toasts, action rows and dense dashboard grids.
- E2E expectations updated to current TCW HR branding and current Calendar UI text.

## Removed or consolidated
- Obsolete one-off 1.2.1–1.2.8 fix instruction files.
- Obsolete `docs/legacy-guides` material superseded by current documentation.
- Unreferenced older `release-website` copy; `marketing-site` remains the maintained website source.
- Empty Android resource directory.
- Added `START-HERE.txt` as the concise current entry point.

## Validation performed
- Parsed all project TypeScript/TSX source files: no syntax diagnostics.
- Parsed all JSON files: valid.
- Checked shared CSS brace balance: valid.
- Checked Windows Electron entry file with Node syntax validation: valid.
- Ran the dependency-light engine test suite by transpiling the required TypeScript sources with TypeScript 5.8.3: 12 tests passed, 0 failed. This covers attendance rules/time zones, payroll calculations/transitions, password hashing, CSV safety and BioMax/ZKTeco behavior.

## Validation limitation
A full `npm ci`, Next.js/Nest build and Playwright integration/E2E run could not be completed in the audit sandbox because the required npm dependency set was not available in its cache and external package retrieval was unavailable. Run `npm ci`, `npm run typecheck`, `npm test`, `npm run build` and `npm run test:e2e` on a machine with normal npm access before production signing/deployment.
