# TCW HR Software v1.2.9 — Trial Follow-up

## Added
- Dedicated **Super Admin → Trial follow-up** workspace.
- Every self-service free-trial signup is automatically tracked with company, owner/contact, email, mobile, plan, company code, trial dates, source, employee usage, last login, sales stage, consent status, follow-up status, notes and next follow-up.
- Trial expiry automatically changes the company to `EXPIRED`, revokes active sessions and marks unresolved trial follow-up as `CALL_DUE`.
- Super Admin dashboard surfaces **Trial calls due** and trials expiring within two days.
- One-click `tel:` and `mailto:` actions for follow-up on supported mobile/desktop apps.
- Follow-up workflow statuses: Pending, Call due, Contacted, No answer, Follow-up, Interested and Not interested.
- Follow-up updates are written to the company trial profile and synchronized into the Sales pipeline lead where available.
- New self-service trials create a Sales pipeline lead with the trial expiry as the initial next-follow-up date.
- Admin-created trials also create a Sales pipeline lead and can capture the owner's mobile number.
- Trial signup now requires a mobile number and explicit trial-contact consent.

## Compatibility
No Prisma schema migration is required for this feature. Trial follow-up metadata is stored in the existing `Tenant.profile` JSON field, while the existing `Lead` model is reused for sales pipeline synchronization.
